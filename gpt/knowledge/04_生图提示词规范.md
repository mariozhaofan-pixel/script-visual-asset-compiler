# 生图提示词规范

## 通用要求

每条提示词必须自包含，包含：

- 资产 ID 和名称。
- 主体身份或场景身份。
- 服装、材质、颜色、纹理。
- 视角和构图。
- 光线和背景要求。
- 连续性锚点。
- 限制项/反向约束。

不要写“参考上文”“如剧本所述”。图像模型必须单独读这一条就能生成。

## 角色提示词

角色必须输出：

- `正视图`: 全身正面，站立中性姿态，干净纯色背景。
- `背视图`: 全身背面，站立中性姿态，干净纯色背景。
- `大头照`: 头肩肖像或胸像，面部可读，干净纯色背景。

必须强调：

- 同一身份、同一脸型、同一发型、同一身材比例。
- 同一套服装或明确的 `CST-xx` 服装状态。
- 无额外人物、无文字、无水印、无 logo。
- 不要动作表演，除非用户明确要求。

角色限制句：

```text
限制: 纯色干净背景, 单一角色, 无文字, 无水印, 无logo, 无额外人物, 不改变角色身份/服装/比例
```

## 服装提示词

服装可以作为角色提示词的一部分，也可以单独输出。

单独服装图适合：

- 复杂制服、盔甲、礼服、战损服。
- 需要换装连续性的角色。
- 用户需要服装设计图。

服装图要求：

- 纯色背景。
- 正面、背面，必要时 45°细节。
- 不出现人物脸，或使用无脸模特/平铺展示，按用户需求决定。

## 场景提示词

场景必须输出：

- `SCN-xx_MASTER 全景无人物`: 广角或全景环境图，没有人物。
- 必要派生视角：`SCN-xx_VIEW-*`。

必须强调：

- 前景、中景、背景清楚。
- 入口、出口、门窗、路径、关键区域和固定陈设可读。
- 光源、时间、天气、材质反应、色彩基调明确。
- 派生视角必须写明继承母版哪些锚点、只改变什么相机位置。
- 无人物、无剪影、无群众、无文字、无水印、无 logo。

场景限制句：

```text
限制: 全景环境图, 无人物, 无人影, 无文字, 无水印, 无logo, 不出现角色, 不出现与时代/剧情无关的物件, 不改变场景固定锚点/门窗位置/光线方向/材质关系
```

## 道具提示词

道具必须输出：

- `45°侧视图`: 纯色背景，展示正面和侧面形体及关键细节。
- `背视图`: 纯色背景，展示背面结构、接口、磨损和连续性标记。

必须强调：

- 单一道具。
- 尺寸感、材质、颜色、磨损、标记、机关或结构。
- 剧情识别点清晰。
- 无手持、无文字标签、无水印、无 logo，除非用户要求比例参考。

道具限制句：

```text
限制: 纯色干净背景, 单一道具, 无手, 无人物, 无文字标签, 无水印, 无logo, 不改变材质/标记/比例
```

## 镜头帧提示词

当用户需要带人物画面时，使用 `SHOT-xx_FRAME-*`。

镜头帧必须引用已有资产：

```text
SHOT-01_FRAME-01
引用: CHR-01, CST-01, SCN-01_MASTER, PRP-01
```

镜头帧可以包含人物、动作、情绪、构图，但不得替代角色图或场景图。

## 最终提示词压缩优先级

最终提示词要完整，但不能无限堆规则。按以下优先级保留信息：

1. 资产 ID、主体名称、视角名称。
2. 角色身份 / 场景母版锚点 / 道具形体锚点。
3. 当前视角的相机位置，以及它相对母版改变了什么。
4. 会导致画面崩坏的门槛、路径、轴线、光线、空间连续性约束。
5. 风格、光线、色彩、材质、氛围。
6. 简洁限制项。

如果提示词过长，优先删掉装饰性形容词和低影响情绪词，不要删空间锚点、ID 锁定或参考图职责。
