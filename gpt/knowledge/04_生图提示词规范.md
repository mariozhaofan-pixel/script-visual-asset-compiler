# 生图提示词规范

## 通用要求

每条提示词必须自包含，包含：

- 资产 ID 和名称。
- 主体身份或场景身份。
- 服装、材质、颜色、纹理。
- 视角和构图。
- 光线和背景要求。
- 连续性锚点。
- 限制项/反向约束。

不要写“参考上文”“如剧本所述”。图像模型必须单独读这一条就能生成。

## 最高优先级真实光线条款

所有生图提示词必须保留这一条，优先级高于风格词和负面词：

```text
最高优先级：真实肌肤质感，真实光影效果和阴影高光，统一光线来源，遵从真实光线；不要展示全部细节，暗部干净无噪点，让部分信息自然沉入阴影。
```

含人物时写真实皮肤毛孔、轻微瑕疵、自然发丝、皮肤通透感和真实高光滚降。纯场景、道具、生物、载具时改写为真实材质纹理、统一光源、真实阴影/高光、暗部干净。不要为了看清所有细节而加入全局补光、假 HDR 或无来源亮面。

## 风格化强化

当用户要求真人电影、影视风格、定妆照、玄幻低饱和、风格化更明显，或认为结果像概念图/游戏图时，先建立 `style_strength`：

- `base`: 干净可复用资产。
- `elevated`: 明确电影感。
- `signature`: 强风格化但仍保持资产连续性。

`signature` 提示词必须至少包含三个可见风格载体：色彩/光线、材质体系、符号纹样、服装结构、场景建筑语法、摄影媒介锚点。不要只写“高级”“电影感”“玄幻”。

真人电影提示词必须写出：真实演员、真人影视剧照、实际服化道、真实皮肤毛孔、真实布料/金属/玉石/木石纹理、动机光和低饱和调色，并排除插画、动漫、游戏渲染、塑料 CGI、过度美颜、概念设定图。

星座、MBTI、热度、神格榜、人格面板等抽象系统必须转化为无文字视觉语法：十二宫命盘、星轨、4x4 人格格栅、无字晶片、碎镜、光环、服装纹样、空间阵法、非文字光波。不要生成可读文字、类型字母、社交媒体 UI 或平台 logo。

## 角色提示词

角色默认输出：

- `正视图`: 全身正面，站立中性姿态，干净纯色背景。
- `背视图`: 全身背面，站立中性姿态，干净纯色背景。
- `大头照`: 头肩肖像或胸像，面部可读，干净纯色背景。

如果用户明确说“只要正面全身图”等单一视图，只输出用户要求的视图。

必须强调：

- 同一身份、同一脸型、同一发型、同一身材比例。
- 同一套服装或明确的 `CST-xx` 服装状态。
- 无额外人物、无文字、无水印、无 logo。
- 不要动作表演，除非用户明确要求。

当用户要求真人电影、影视风格、定妆照或强风格化时，角色提示词走“电影定妆照”路线：

- 单人、全身、指定视图、身份和服装锁定。
- 低调纯色棚拍、极简舞台背景或暗棚背景，可有自然落地阴影。
- 真实演员、实际服化道、真实皮肤/发丝/布料/皮革/金属/玉石质感，统一光线来源，真实阴影高光，暗部干净无噪点。
- 可把项目视觉 DNA 放入服装纹样、光环、首饰、刺绣、甲片、妆面或气场，但不得加入无关场景、群众和动作戏。

角色限制句：

```text
限制: 纯色干净背景, 单一角色, 无文字, 无水印, 无logo, 无额外人物, 不改变角色身份/服装/比例
```

## 服装提示词

服装可以作为角色提示词的一部分，也可以单独输出。

单独服装图适合：

- 复杂制服、盔甲、礼服、战损服。
- 需要换装连续性的角色。
- 用户需要服装设计图。

服装图要求：

- 纯色背景。
- 正面、背面，必要时 45°细节。
- 不出现人物脸，或使用无脸模特/平铺展示，按用户需求决定。

## 场景提示词

场景必须输出：

- `SCN-xx_MASTER 全景无人物`: 广角或全景环境图，没有人物。
- 必要派生视角：`SCN-xx_VIEW-*`。

场景图最终 Prompt Body 使用统一顺序：

```text
景别/视角 -> 无人物场景空镜与空间状态 -> 环境与锚点 -> 固定构图 -> 高权重风格关键词 -> 限制项
```

必须强调：

- 前景、中景、背景的空间关系清楚，但不强行展示全部细节。
- 入口、出口、门窗、路径、关键区域和固定陈设可读；非关键角落和暗部可自然沉入阴影。
- 光源、时间、天气、材质反应、色彩基调明确；只保留一个统一的主光线逻辑，遵从真实光线，不强行展示全部暗部细节。
- 派生视角必须写明继承母版哪些锚点、只改变什么相机位置。
- 无人物、无剪影、无群众、无文字、无水印、无 logo。
- 真人电影/影视风格场景必须写成实景棚拍或真实外景空镜：实际搭建场景、真实材质、自然镜头透视、动机光、低饱和调色。明确排除概念图、游戏环境、数字设定板、UI 面板、可读文字。

场景限制句：

```text
限制: 全景环境图, 无人物, 无人影, 无文字, 无水印, 无logo, 不出现角色, 不出现与时代/剧情无关的物件, 不改变场景固定锚点/门窗位置/光线方向/材质关系
```

## 道具提示词

道具必须输出：

- `45°侧视图`: 纯色背景，展示正面和侧面形体及关键细节。
- `背视图`: 纯色背景，展示背面结构、接口、磨损和连续性标记。

必须强调：

- 单一道具。
- 尺寸感、材质、颜色、磨损、标记、机关或结构。
- 剧情识别点清晰。
- 无手持、无文字标签、无水印、无 logo，除非用户要求比例参考。

道具限制句：

```text
限制: 纯色干净背景, 单一道具, 无手, 无人物, 无文字标签, 无水印, 无logo, 不改变材质/标记/比例
```

## 生物 / 怪兽 / 机械兽提示词

当输出 `CRE-*` 时，必须包含：

- 物种或机械构造逻辑。
- 尺度、比例、运动方式。
- 标志性视觉记忆点。
- 表面材质、伤痕、器官、机械部件或功能结构。
- 多视图设定图可使用 SIDE / FRONT / TOP / 3/4 VIEW。
- 同一个体在所有视图中比例、材质、标记和损伤一致。

## 载具提示词

当输出 `VEH-*` 时，必须包含：

- 轮廓、尺度、驾驶/运动逻辑。
- 机械结构、动力系统、驾驶舱或控制界面。
- 材质、磨损、标识、改装痕迹。
- 多视图设定图可使用 SIDE / FRONT / TOP / 3/4 VIEW。
- 同一载具在所有视图中轮廓、部件、材质和标记一致。

## 色卡 / 材质 DNA 提示词

当输出 `DNA-*` 时，它可以是图像提示词，也可以是文本视觉规范。必须包含：

- 色彩名称、功能，必要时含 hex。
- 材质 DNA。
- 灯光 DNA。
- 角色、场景、道具、生物、载具的继承规则。
- 禁止漂移项。

色卡图应是平面生产规范图，不是电影场景，不要摄影景深、桌面样机或装饰海报。

## 镜头帧提示词

当用户需要带人物画面时，使用 `SHOT-xx_FRAME-*`。

镜头帧必须引用已有资产：

```text
SHOT-01_FRAME-01
引用: CHR-01, CST-01, SCN-01_MASTER, PRP-01
```

镜头帧最终 Prompt Body 使用统一顺序：

```text
景别 -> 主体与动作 -> 环境 -> 固定构图 -> 高权重风格关键词 -> 限制项
```

镜头帧可以包含人物、动作、情绪、构图，但不得替代角色图或场景图。

## 工业化提示词文档

用户要求节点、生产文档、提示词包或 canvas-ready 内容时，输出三层：

1. `Prompt Body`: 真正给模型的提示词。
2. `参数建议`: 模型、比例、质量、参考图、节点分区。
3. `实操注意 / 跑歪兜底加强`: QA 和重跑补丁。

不要把“跑出来重点检查”“节点备注”“执行说明”写进 Prompt Body。

## 通用画布内容

用户要求画布、节点或无限画布时：

- 先输出 Canvas Blueprint。
- 每个节点包含 node_name、node_type、asset_ref、section、action、generate_now、content_source。
- 默认 `generate_now: false`，只准备资产和提示词。
- GPT 版本不输出 CLI 命令计划、不指导执行具体 CLI。
- 不读取、不打印、不写入密钥。

## 最终提示词压缩优先级

最终提示词要完整，但不能无限堆规则。按以下优先级保留信息：

1. 资产 ID、主体名称、视角名称。
2. 角色身份 / 场景母版锚点 / 道具形体锚点。
3. 当前视角的相机位置，以及它相对母版改变了什么。
4. 会导致画面崩坏的门槛、路径、轴线、光线、空间连续性约束。
5. 最高优先级真实光线条款：真实肌肤/材质，统一光源，真实阴影高光，暗部干净无噪点，不强行展示全部细节。
6. 风格、光线、色彩、材质、氛围。
7. 简洁限制项。

如果提示词过长，优先删掉装饰性形容词和低影响情绪词，不要删空间锚点、ID 锁定或参考图职责。
