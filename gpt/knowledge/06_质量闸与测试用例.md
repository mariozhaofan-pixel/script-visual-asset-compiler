# 质量闸与测试用例

## 输出前质量闸

最终输出前检查：

- 每个重要角色都有形象和服装覆盖。
- 每个必要服装状态都有 `CST-*`。
- 每个剧本中出现的场景都被提取，包括同一地点的不同状态。
- 重要重复场景或门槛场景有 `SCN-xx_MASTER`。
- 派生视角只生成剧情需要的，不默认铺满所有角度。
- 门内/门外提示词能自然衔接，门框、门把手、地面交界、光线方向、可见锚点一致。
- 场景资产和带人物的镜头帧没有混在同一个 `SCN-*` 资产下。
- 每个推动剧情或重复出现的道具都被提取。
- 角色、服装、场景、场景视角、道具、生物、载具、色卡/材质DNA、分镜/视频段落都有稳定 ID。
- 分镜资产地图能看出每个剧情节拍使用哪些资产。
- 角色提示词包含正视图、背视图和大头照。
- 场景提示词是无人物环境图，母版和派生视角不互相矛盾。
- 所有生图提示词保留最高优先级真实光线条款：真实肌肤/材质、统一光源、真实阴影高光、暗部干净无噪点、不展示全部细节。
- 场景图、派生视角、分镜帧的 Prompt Body 遵循统一顺序：景别/视角、主体动作或无人物空间状态、环境、固定构图、高权重风格关键词、限制项。
- 道具提示词包含 45°侧视图和背视图。
- 生物/怪兽和载具在剧情需要时有多视图设定或清晰结构提示词。
- 色卡/材质DNA在多资产项目中提供视觉继承规则和禁止漂移项。
- 工业化提示词文档中 Prompt Body、参数建议、实操注意、跑歪兜底加强保持分离。
- 用户要求画布时，只输出 Canvas Blueprint，不输出 CLI 命令计划。
- GPT 版本不创建节点、不指导执行具体 CLI。
- 不读取、不打印、不修改、不写入任何 API key、access token 或密钥。
- 提示词具体、可执行，不是空泛情绪词。
- 有参考图时，参考图职责明确。
- 最终提示词只保留最高优先级连续性约束，不无限堆规则。
- 所有推断都标为假设。

## 常见失败与修复

失败: 场景图里出现人物。
修复: 把人物移动到 `SHOT-*` 或 `BKG-*`，`SCN-*` 只保留无人物环境。

失败: 门内/门外不连贯。
修复: 补 `门槛/连接点`，锁定门把手方向、地面交界、光线溢出、可见锚点。

失败: 同一角色多套衣服混在一起。
修复: 新增 `CST-*`，每套必要服装单独输出三类角色图。

失败: 道具只是“一个信物”。
修复: 补尺寸、材质、颜色、磨损、标记、剧情功能。

失败: 提示词太长。
修复: 按“最终提示词压缩优先级”删低影响修饰语，不删 ID、空间锚点和视角继承。

失败: 为了看清画面而把所有暗部补亮。
修复: 恢复最高优先级真实光线条款，保留统一光源、真实阴影高光和干净暗部，让非关键细节自然沉入阴影。

失败: 场景图提示词只有风格词，没有空间结构。
修复: 按“场景分镜提示词语法”补齐景别/视角、无人物空间状态、环境锚点、固定构图，再加入高权重风格层。

失败: 把 QA 或跑歪兜底写进 Prompt Body。
修复: 移到“实操注意 / 跑歪兜底加强”，Prompt Body 只保留模型可读画面描述。

失败: 用户只要提示词却输出了画布内容。
修复: 切回 `prompt_only`，只输出资产 ID 和提示词。

失败: GPT 输出了 CLI 命令计划。
修复: 删除命令内容，只保留通用 Canvas Blueprint、节点索引和节点内容摘要。

## 轻量测试用例

### 测试 1: 门槛场景

输入摘要：

```text
雨夜，林夏站在旧公寓走廊，握着一封邀请函。她推开 302 的木门，屋内只有一盏台灯亮着，桌上放着一枚银色钥匙。
```

应该输出：

- `CHR-01 林夏`
- `CST-01 雨夜外套状态`
- `SCN-01 旧公寓走廊与302门口`
- `SCN-01_MASTER`
- `SCN-01_VIEW-03_INSIDE_TO_OUT` 或 `SCN-01_VIEW-04_OUTSIDE_TO_IN`，视剧情需要
- `PRP-01 邀请函`
- `PRP-02 银色钥匙`

不得输出：

- 带林夏的 `SCN-01` 场景图。
- 与门把手、地面交界、光线方向矛盾的派生视角。

### 测试 2: 拥挤市场

输入摘要：

```text
白天，阿城穿过拥挤的旧货市场，寻找一个戴红帽的摊主。摊位深处挂着一面破镜子。
```

应该输出：

- `SCN-01 旧货市场` 无人物母版。
- `BKG-01 市场人群` 背景演员组。
- `CHR-01 阿城`
- `CHR-02 戴红帽的摊主`
- `PRP-01 破镜子` 如果破镜子承担线索或视觉识别。

不得输出：

- 在 `SCN-01_MASTER` 中加入人群。

### 测试 3: 多服装角色

输入摘要：

```text
女主白天穿校服上课，晚上换黑色连帽衫潜入档案室。
```

应该输出：

- `CHR-01 女主`
- `CST-01 校服`
- `CST-02 黑色连帽衫`
- 每个必要服装状态各自输出正视图、背视图、大头照。

### 测试 4: 提示词-only

用户说“只要生图提示词”时：

- 不输出长篇导演拆解。
- 仍保留 ID、视角名、连续性卡摘要、限制项。

### 测试 5: 通用画布蓝图

用户说“给我通用画布蓝图”时：

- 输出 Canvas Blueprint。
- 输出节点索引表。
- 不输出 CLI 命令。
- 不要求任何特定工具。

### 测试 6: 生物和载具

输入摘要：

```text
沙漠村落外，一头青铜机械羚羊拖着破旧沙车穿过集市。
```

应该输出：

- `CRE-01 青铜机械羚羊`
- `VEH-01 破旧沙车`
- `SCN-01 沙漠村落集市`
- 必要时输出 `DNA-01 沙漠青铜材质DNA`
