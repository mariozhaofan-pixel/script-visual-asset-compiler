# 资产提取规则

## ID 规则

使用稳定 ID：

- `CHR-01`: 角色身份。
- `CST-01`: 服装或角色服装状态。
- `SCN-01`: 场景母体/地点/地点状态。
- `SCN-01_VIEW-01_PRIMARY`: 同一场景派生视角。
- `PRP-01`: 关键道具。
- `CRE-01`: 生物、怪兽、机械兽、坐骑、变异生命或非人实体。
- `VEH-01`: 载具、飞船、车辆、机甲、船、飞行器、交通工具。
- `DNA-01`: 色卡、材质体系、灯光规则、项目视觉DNA。
- `STB-01`: 九宫格分镜、分镜表、关键帧网格或序列板。
- `VID-01`: 视频段落、图生视频/文生视频计划。
- `BKG-01`: 背景演员组、群众、路人、学生、宴会宾客等，不作为场景图的一部分。
- `SHOT-01_FRAME-01`: 带人物、动作、构图的镜头帧或关键帧。

同一个对象重复出现时复用原 ID，不要另起 ID。只有身份、状态、地点状态或功能发生实质变化时才新增 ID。

## 角色

提取：

- 有名字的角色。
- 没名字但承担剧情功能、视觉功能或反复出现的角色。
- 背景演员组，如果其数量、服装、行为会影响画面。

角色描述包含：

- 年龄段、体型、脸型、发型、显著面部特征。
- 基础表情、姿态、社会身份、气质。
- 与其他角色的视觉对比。
- 不确定信息标为假设。

## 服装

服装状态必须和角色身份分开。以下情况创建 `CST-*`：

- 日常装、制服、礼服、伪装、战损、雨夜湿透、血污、尘土、睡衣、职业装。
- 剧情中服装变化影响识别、身份、阶层、时序或情绪。
- 同一角色在不同场景需要不同服装连续性。

每个 `CST-*` 绑定角色，例如：

```text
CST-01: CHR-01 日常黑色风衣
CST-02: CHR-01 雨夜湿透状态
```

## 场景

提取剧本中所有明确场景。以下情况拆成不同场景状态：

- 白天/夜晚
- 完好/破坏
- 空无一人/拥挤
- 晴天/雨天/雪天
- 整洁/凌乱
- 同一地点但空间区域不同，且镜头无法共享一个母版

场景是空间资产，不是氛围标签。必须描述：

- 空间结构、比例、纵深、前中后景。
- 入口、出口、门、窗、走廊、楼梯、路径。
- 固定陈设和固定锚点。
- 材质、光源、色彩、天气、气氛。

场景资产 `SCN-*` 永远不含人物。

## 背景演员组

如果剧本需要群众、路人、学生、宴会宾客、保镖、警察队伍等，创建 `BKG-*`：

- `BKG-*` 不属于场景母版。
- `BKG-*` 可用于镜头帧或视频提示词。
- 若用户只要场景图，先输出无人物 `SCN-*`；群众另列。

## 关键道具

提取推动剧情、揭示身份、反复出现、制造冲突、代表关系或需要连续性的物品。

典型道具：

- 邀请函、武器、信物、戒指、项链、合同、手机、药物、信件、照片、面具、钥匙、仪式物、特殊容器、车辆、设备、线索物。

不要把普通背景家具都列为关键道具，除非它参与动作、识别、冲突、空间连续或叙事反转。

道具描述必须包含：

- 尺寸、材质、颜色、磨损、标记。
- 文字/图案位置。
- 机械结构或可打开/可使用方式。
- 独特识别点和剧情功能。

## 生物 / 怪兽 / 机械兽

提取所有具有剧情功能、视觉记忆点或后续镜头复用价值的非人实体。描述必须包含：

- 物种或构造逻辑。
- 尺度、比例、运动方式。
- 标志性记忆点。
- 表面材质、伤痕、器官或机械部件。
- 与角色、场景或道具的关系。

## 载具

提取所有承担行动、世界观或视觉识别功能的载具。描述必须包含：

- 轮廓和尺度。
- 驾驶/运动逻辑。
- 机械结构、动力系统、驾驶舱或控制界面。
- 材质、磨损、标识、改装痕迹。

## 色卡 / 材质 DNA

当项目需要统一视觉风格时创建 `DNA-*`。必须包含：

- 5-8 个核心颜色及功能。
- 材质体系。
- 光线规则。
- 角色、场景、道具、生物、载具如何继承该 DNA。
- 禁止漂移项。

## 分镜 / 视频段落

- `STB-*` 用于九宫格分镜、关键帧网格、序列板。
- `SHOT-*` 用于单张带人物/动作/构图的画面。
- `VID-*` 用于视频段落提示词或图生视频计划。

分镜和视频必须引用已有资产 ID，不要在分镜层发明新的角色、服装、场景或道具事实。
