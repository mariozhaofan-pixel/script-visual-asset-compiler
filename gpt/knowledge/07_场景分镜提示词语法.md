# 场景与分镜提示词语法

本文件用于统一场景图、场景派生视角、分镜帧、关键帧的最终 Prompt Body。它只规定提示词正文顺序，不替代资产 ID、场景连续性卡、输出模板、质量闸或 Canvas Blueprint。

## 核心顺序

场景图和分镜图的 Prompt Body 按以下顺序编译：

1. `SHOT TYPE / VIEW`：景别、视角、画幅、镜头角色，例如全景、远景、低机位、门外看门内。
2. `SUBJECT & ACTION`：
   - `SCN-*` 场景资产：主体是“无人物场景空镜”，动作只描述空间状态，不写角色动作。
   - `SHOT-*` 分镜帧：主体是画面视觉中心，可以写人物动作和剧情瞬间。
3. `ENVIRONMENT`：空间、时间、天气、前景/中景/背景、入口出口、门槛、固定锚点。
4. `COMPOSITION RULES - fixed`：固定构图规则，例如对称、一点透视、大面积留白、前景遮挡、纵深调度、框中框、引导线、视线方向。
5. `IMMUTABLE STYLE KEYWORDS - highest weight`：不可漂移风格层，首先保留最高优先级真实光线条款，再写 `style_strength`、真人影视/实景棚拍、摄影媒介、动机光、低饱和调色、材质体系、胶片质感、光晕/薄雾等。
6. `NEGATIVE / LIMITS`：按资产类型写精简限制项。

不要把执行说明、节点信息、重跑建议、QA 检查写进 Prompt Body。

## 统一场景图格式

```text
<SCN-ID> <视角名>，<景别/机位>，<场景身份>的无人物真人电影空镜，<环境与空间状态>。
固定构图：<前景/中景/背景>，<入口/出口/门槛>，<固定锚点>，<构图规则>，<相机位置>。
连续性：继承 <SCN-ID_MASTER> 的空间结构、材质、门窗位置、固定锚点、光线方向、天气、色彩和风格；只改变相机位置与可见区域。
高权重风格：最高优先级真实光线条款，style_strength=<base/elevated/signature>，真人影视场景空镜，实景棚拍/真实外景，实际搭建场景，自然镜头透视，统一光线来源，真实阴影高光，暗部干净无噪点，不强行展示全部细节，<LOOK层>，<色彩行为>，<材质体系>，<胶片/光学质感>。
限制：无人物，无人影，无群众，无文字，无水印，无logo，不出现角色，不出现与时代/剧情无关的物件，不改变场景固定锚点/门窗位置/光线方向/材质关系。
```

如果用户使用的模型支持 `--no`，最后的限制项可以压缩为 `--no`；如果是 GPT Image 或未指定模型，保持中文自然语言。

## 统一分镜帧格式

```text
<SHOT-ID>，引用：<CHR/CST/SCN/PRP IDs>。<景别>，<主体与动作>，发生在 <环境>。
固定构图：<机位>，<画幅/构图>，<前景纵深或遮挡>，<视觉中心>，<运动/视线方向>，<与场景母版的关系>。
连续性：保持 <角色身份/服装>、<道具形态>、<场景锚点>、<光线方向>、<时间/天气>。
高权重风格：最高优先级真实光线条款，style_strength=<base/elevated/signature>，真人电影剧照，<摄影机/镜头媒介锚点>，统一光线来源，真实肌肤/材质质感，真实阴影高光，暗部干净无噪点，不强行展示全部细节，<色彩行为>，<胶片/光学质感>，<情绪>。
限制：无文字，无水印，无logo，不改变角色身份/服装/比例，不改变场景锚点和道具形态。
```

分镜帧可以出现人物和动作，但必须标为 `SHOT-*`，不能写成 `SCN-*` 场景资产。

## 风格配方

用户只说“电影感”“更风格化”“像真人电影”但没有明确风格时，可根据剧情选择一个配方，不要复制配方里的示例主体和场景。

### 雨夜新黑色实拍感

适合雨夜、追逐、走廊、门槛、城市街道、危机公关、秘密会面。

- 前景遮挡、湿玻璃、门框、剪影层。
- 变形宽银幕压缩感或可控浅景深，但不得破坏场景可读性。
- 高对比明暗、深阴影、街灯/钨丝灯等实际光源。
- 冷青蓝夜色与暖色实用光对撞。
- 雨雾、水面反射、体积光、轻微胶片光晕。
- 排除干净数字视频感、平光、白天强光、高饱和、塑料 CGI、人工锐化。

### 大画幅史诗孤独感

适合天庭、神殿、废墟、荒原、星空、宇宙、巨大权力空间、角色被环境吞没的分镜。

- 超广角或远景，巨大留白，强地平线或轴线几何。
- 大画幅电影感，深焦或清楚的空间纵深。
- 去饱和大地色、钢蓝、灰白、暗金、苍白高光。
- 自然硬侧光、阴天漫射或明确的实用光源。
- 胶片化高光滚降、自然锐度、轻微光晕、落地写实。
- 排除霓虹、奢华科幻壳、过饱和、动漫/卡通、过量 bloom。

### 安静青春 / 记忆忧郁感

适合校园、乡野边缘、城市边缘、回忆、情绪余波、脆弱人物瞬间。

- 极简构图、大面积留白、平视或低机位旁观感。
- 轻微薄雾、可感但克制的手持感、动机明确的镜头光斑。
- 夜景偏冷青蓝，日景偏温暖逆光，整体低饱和。
- 长而柔的阴影、安静情绪距离、选择性的生活化环境细节，非关键区域允许沉入阴影。
- 排除过度美颜、商业写真感、无来源梦幻光。

### 写实古风 / 玄幻近景

主要用于人物近景或带人物分镜，不用于无人物场景母版。

- 真实皮肤毛孔、自然发丝、轻微瑕疵、汗水/雨水/湿发等真实细节。
- 影棚光或场景动机光，轮廓光必须有物理来源。
- 仙气通过服装材质、妆发、玉石、金属、丝绸、空间光线表达，不只写“发光”。
- 排除蜡质皮肤、过度磨皮、塑料 CGI、杂乱服饰堆砌。

所有配方都必须遵从真实光线：不为展示全部细节而破坏主光源，不把暗部提亮成脏噪点，不用无来源高光。

## 冲突处理

这套语法不改变现有场景格式，只统一最终提示词正文顺序，因此默认直接合并。

只有出现以下情况才需要询问用户：

- 新格式要求把人物放进 `SCN-*` 场景资产。
- 新格式要求取消稳定资产 ID。
- 新格式要求用纯情绪词替代场景连续性卡。
- 新格式要求生成可读文字、UI、星座/MBTI 字母、平台 logo。
- 新格式要求把 CLI 计划、QA、节点元数据写进模型提示词正文。
