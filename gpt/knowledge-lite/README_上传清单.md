# 剧本资产提取器 GPT 轻量版上传清单

轻量版适合 GPT 创建器知识库容量有限、希望执行更快、更稳的场景。它保留资产提取、场景连续性、电影感 LOOK、防廉价和模型适配，但不包含完整 preset/参数大表。

建议上传本文件夹内全部 `.md` 文件：

1. `00_GPT轻量创建配置.md`
2. `01_轻量主控协议.md`
3. `02_电影感风格层.md`
4. `03_防廉价与模型适配.md`
5. `04_轻量输出模板.md`

`剧本资产提取器_轻量版_GPT创建修改提示词.md` 是给 GPT 创建器对话框粘贴用的，可上传也可不上传。

若同时上传完整版和轻量版，必须明确：完整版文件优先，轻量版只作为快速执行摘要。
