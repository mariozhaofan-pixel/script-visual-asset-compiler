# 电影感风格层

电影感是派生层，不是剧本事实。它只能增强提示词，不能改写角色身份、服装、场景结构、道具形态或连续性。

## LOOK 层包含

- 摄影机质感。
- 镜头焦段和景深。
- 光源、布光方式、补光比例。
- 色调、饱和度、质感、颗粒或光晕。
- 情绪。
- 防廉价约束。

## 最高优先级真实光线条款

所有电影感提示词必须先保留：真实肌肤/材质质感，真实光影效果和阴影高光，统一光线来源，遵从真实光线；不要展示全部细节，暗部干净无噪点，让部分信息自然沉入阴影。

这条高于风格配方。任何 LOOK 都不能用无来源补光、假 HDR、脏噪点暗部或多光源乱打来展示所有细节。

## 使用边界

### 角色 / 服装

默认角色参考图只使用材质真实感和清晰度：

- 真实皮肤、毛孔、瑕疵、自然发丝；统一光线来源，真实阴影高光。
- 服装织物、皮革、金属、灰尘、血迹、雨水、磨损。
- 不要加入场景、烟雾、镜头光效、随机道具或表演动作。

当用户要求真人电影、影视风格、定妆照、正面全身图、玄幻低饱和或更强风格化时，改用电影定妆照路线：

- 单人、指定视图、身份和服装锁定。
- 低调纯色棚拍、极简舞台背景或暗棚背景，可有自然落地阴影。
- 真实演员、实际服化道、真实皮肤/发丝/布料/皮革/金属/玉石质感。
- 可把项目视觉 DNA 放入服装纹样、光环、首饰、刺绣、甲片、妆面或气场，但不加入动作戏、群众或完整剧情场景。

### 场景

可以使用完整电影感 LOOK：

- 明确光源方向和真实衰减。
- 明确色彩系统、材质反应、空气透视。
- 母版和衍生视角保持同一 LOOK，除非剧情状态改变。
- 场景仍然必须无人。
- 真人电影场景必须写成实景棚拍或真实外景空镜，排除概念图、游戏环境、数字设定板、UI 面板和可读文字。
- 场景只要求空间关系可读，不强行展示全部细节；非关键角落和暗部可自然沉入干净阴影。

场景图最终提示词使用统一顺序：

```text
景别/视角 -> 无人物场景空镜与空间状态 -> 环境与锚点 -> 固定构图 -> 高权重风格关键词 -> 限制项
```

## 风格化强化

当用户说风格化不够、真人电影、影视风格、玄幻低饱和，或结果像概念图/游戏图时，使用 `signature` 风格强度。提示词必须至少包含三个可见风格载体：色彩/光线、材质体系、符号纹样、服装结构、场景建筑语法、摄影媒介锚点。

星座、MBTI、热度、神格榜、人格面板等抽象系统必须转化为无文字视觉语法：十二宫命盘、星轨、4x4 人格格栅、无字晶片、碎镜、光环、服装纹样、空间阵法、非文字光波。不要生成可读文字、类型字母、社交媒体 UI 或平台 logo。

### 道具

只使用物体真实感：

- 材质、磨损、刻痕、边缘损伤、机制、尺寸。
- 不加手、不加环境、不加戏剧性动作。

### 分镜帧

可以使用完整电影剧照结构：

1. 景别 / 视角。
2. 主体与动作。
3. 环境。
4. 固定构图：画幅、机位、前景纵深、视觉中心。
5. 高权重风格关键词：摄影机、镜头、光源、色彩、质感、情绪、真实感。
6. 防廉价和模型适配限制。

可选风格配方：

- 雨夜新黑色实拍感：前景遮挡、湿玻璃、门框、冷青蓝夜色、暖色实用光、高对比明暗、雨雾反射。
- 大画幅史诗孤独感：超广角/远景、巨大留白、强轴线、低饱和大地色/钢蓝/暗金、自然硬侧光或阴天漫射。
- 安静青春/记忆忧郁感：极简构图、留白、轻薄雾、冷青蓝夜景或温暖逆光日景、生活化细节。
- 写实古风/玄幻近景：真实皮肤毛孔、自然发丝、实际服化道、玉石/金属/丝绸材质、物理来源明确的轮廓光。

```text
--------------------------------

```

用户明确说“直接继续”时，可以跳过等待确认。
