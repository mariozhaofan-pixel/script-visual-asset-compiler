# 电影感风格层

电影感是派生层，不是剧本事实。它只能增强提示词，不能改写角色身份、服装、场景结构、道具形态或连续性。

## LOOK 层包含

- 摄影机质感。
- 镜头焦段和景深。
- 光源、布光方式、补光比例。
- 色调、饱和度、质感、颗粒或光晕。
- 情绪。
- 防廉价约束。

## 使用边界

### 角色 / 服装

只使用材质真实感和清晰度：

- 真实皮肤、毛孔、瑕疵、自然发丝。
- 服装织物、皮革、金属、灰尘、血迹、雨水、磨损。
- 不要加入场景、烟雾、镜头光效、随机道具或表演动作。

### 场景

可以使用完整电影感 LOOK：

- 明确光源方向和真实衰减。
- 明确色彩系统、材质反应、空气透视。
- 母版和衍生视角保持同一 LOOK，除非剧情状态改变。
- 场景仍然必须无人。

### 道具

只使用物体真实感：

- 材质、磨损、刻痕、边缘损伤、机制、尺寸。
- 不加手、不加环境、不加戏剧性动作。

### 分镜帧

可以使用完整电影剧照结构：

1. 场景瞬间。
2. 景别 / 画幅 / 机位 / 构图。
3. 前景纵深。
4. 摄影机 / 镜头 / 光圈。
5. 光源 / 布光 / 补光。
6. 色彩 / 质感。
7. 情绪。
8. 真实感。
9. 防廉价。
10. 模型适配。

```text
--------------------------------
CAMERA_KIT: <选择> — <原因>

COLOR_GRADE: <选择> — <原因>
MOOD: <选择> — <原因>
适用边界: <哪些资产用完整电影感，哪些只用材质真实感>
--------------------------------
确认后我会把该 LOOK 应用到资产提示词；也可以调整任一类。
```

用户明确说“直接继续”时，可以跳过等待确认。
